Presentamos el dashboard de Vigilancia de Olas de Calor Santa Marta, 2021-2026.

El dashboard de Vigilancia de Olas de Calor es una herramienta interactiva que estará apoyando la formación de personal de salud pública,
investigación y toma de decisiones políticas en salud pública.

Basado en las necesidades de investigaciones previas hemos aprovechado las ventajas del uso de la IA de ChatGPT como asistente. 
Es así como presentamos este dashboard, el cual está conformado por diferentes paneles, como: 

📊 Climatología de referencia de Santa Marta, para el período 1991–2020
Construcción del umbral diario P90 de temperatura máxima.
Ventana móvil de ±15 días siguiendo el período climatológico de referencia de la OMM.

🌡️ Evaluación de olas de calor de Santa Marta, para el período 2021–2026
Identificación automática de olas de calor cuando la temperatura máxima supera el P90 durante tres o más días consecutivos.

Cálculo de indicadores de olas de calor según Perkins como HWN, HWF, HWD y HWA.

Otros paneles/herramientas son:

✅ Detección y análisis de eventos de olas de calor.
✅ Comparación anual de indicadores.
✅ Consulta de temperaturas recientes y pronósticos mediante la API de Open-Meteo.
✅ Recomendaciones de protección para la población frente a eventos de calor extremo.

Esta herramienta se generó como un apoyo para la investigación, la vigilancia climática y la adaptación al cambio climático, 
integrando evidencia científica y tecnologías abiertas para facilitar la interpretación de los eventos de calor extremo en Santa Marta. 

Accede al dashboard: https://lnkd.in/eN-2YH97
